# AGENTS.md

Инструкции для AI-агентов, работающих в этом репозитории.

## Version bump — обязателен при изменениях скиллов

При любых изменениях скиллов (правки `skills/<skill>/SKILL.md`, добавление/удаление скилла)
**обязательно** поднимай версию patch-bump (например, `2.0.18` → `2.0.19`) во **всех** перечисленных ниже
файлах и во **всех** местах версии внутри них. Нельзя обновлять версию частично.

Версия должна совпадать везде — один и тот же номер во всех трёх файлах.

### Файлы, в которых обязателен version bump

1. `nessy-extension.json` — поле `version`
2. `qwen-extension.json` — поле `version`
3. `.claude-plugin/marketplace.json` — версия в **двух** местах:
   - `metadata.version`
   - `plugins[0].version`

### Порядок действий

1. Внеси изменения в скилл.
2. Подними версию patch-bump во всех трёх файлах (во всех местах версии внутри `marketplace.json`).
3. Убедись, что номер версии одинаков во всех файлах.
4. Закоммить вместе с изменениями скилла (по конвенции: `Bump version to X.Y.Z; <что изменилось>`).
